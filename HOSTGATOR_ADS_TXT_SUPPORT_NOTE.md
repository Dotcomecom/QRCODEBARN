# HostGator Support Note: /ads.txt ModSecurity block

Site: https://www.qrcodebarn.com/

Problem:
`/ads.txt` is still being blocked for standard browser user-agents by ModSecurity.

Latest live verification:
- `https://www.qrcodebarn.com/ads.txt` returns `HTTP 406` for `Mozilla/5.0`
- The response body says: `This error was generated by Mod_Security.`
- The same URL returns `HTTP 200` for Chrome-like user-agents, `curl`, `Googlebot`, and `AdsBot-Google`
- A cache-busted browser request (`/ads.txt?check=now`) also returns `HTTP 406`

Expected ads.txt contents:
`google.com, pub-2378599294878032, DIRECT, f08c47fec0942fa0`

Request:
Please add a path-level ModSecurity/WAF exception for `/ads.txt` so it returns `HTTP 200` for all user-agents on both apex and www hosts.

Key evidence:
- Browser UA: `Mozilla/5.0` -> `HTTP 406`
- Google crawler UA: `AdsBot-Google` -> `HTTP 200`
