How big should a printed QR code be?

Use the 10:1 scan-distance rule to estimate a starting size, then test a real proof with the final artwork, material and lighting.

The 10:1 rule in one sentence

Divide the expected scanning distance by 10: a code scanned from 50 cm should start at about 5 cm wide, including its quiet zone.

QR print size calculator

Starting size: 3 cm / 1.18 in. Print one proof and test it in context.

2 × 2 cm is the usual floor for a simple URL code scanned at arm’s length. Treat that as a practical baseline, not a universal guarantee. More encoded data creates smaller modules and may need a larger physical code.

These dimensions include the quiet zone. They assume a short URL, strong dark-on-light contrast and a flat, non-reflective surface.

Why logos and colours force a bigger code

A logo covers modules, while low-contrast colours make module edges harder for a camera to distinguish. Error correction can recover limited damage, but it does not make every design reliable. Increase the size, keep the logo modest, and test the final exported artwork whenever you change colour or add branding.

Quiet zone is part of the size, not extra

The empty border around a QR code must be at least four modules wide on every side. Include that quiet zone inside the dimensions you give your designer or printer. Do not let text, borders, crop marks or background patterns enter it.

How to test size with a phone, not a ruler only

  1. Print the code at its intended final dimensions without “fit to page” scaling.
  2. Place it where people will scan it, with the finished lighting and surface.
  3. Start at the expected distance and scan with both iPhone and Android cameras.
  4. Test from a slight angle and with an older phone if your audience may use one.
  5. Increase the code until scanning is quick and repeatable, then approve the run.

Generate at the right export size

Use SVG whenever possible because it stays sharp at any output size. If a printer requires PNG, export enough pixels for the final dimensions at 300–600 DPI and do not enlarge it later.
