Use a guest network

Create the code for an isolated guest network rather than the network used by staff devices, tills, cameras or business systems. Anyone who can see the printed code can read or share its stored credentials.

Before displaying the code

  • Match the network name, password and security type exactly.
  • Test joining on both iPhone and Android.
  • Provide the network name and a manual fallback where appropriate.
  • Replace every printed sign when the password changes.

Print a WiFi sign

For a counter or reception sign, start with a 4–5 cm code including its quiet zone. Download SVG for print and use a matte surface where glare is likely.
